# OST — On-Screen Translator

OSTはmacOS 26以降で動作するメニューバーアプリです。システムオーディオを文字起こしし、オンデバイス翻訳の字幕をフローティングオーバーレイに表示します。動画や会議でテキストが消えたり、点滅したり、重複したりすることを深刻な使い勝手上の問題と捉えて設計されています。

## 主な特長

- Apple SpeechとApple Translationを標準のオンデバイスプロバイダーとして使用します。
- 対応するシステムロケールが利用できる場合、Apple Speechは英語、中国語（簡体字・繁体字）、日本語、韓国語をサポートします。
- オプションのQwen3 ASRおよび翻訳モデルは、MLXを使用してローカルで動作します。
- 確定した文字起こしと翻訳の履歴を表示したまま、現在のプレビュー用にそれぞれ2行を確保します。
- 文字起こしと翻訳の各領域には確定済みの内容を2～10行表示でき、この値を変更するとウインドウのサイズも変わります。
- デフォルトは左揃えで、中央揃えと右揃えも選択できます。
- 原文、確定した翻訳、現在の翻訳プレビューについて、フォントと色を個別に設定でき、ライブサンプルも表示されます。
- EPDは翻訳のソフト境界として使われ、一時停止のたびに新しい表示行を強制することはありません。
- アプリのUIは英語、中国語、日本語、韓国語に対応しています。デフォルトは英語です。
- セッションごとの文字起こし・翻訳ファイルの保存はオプションで、デフォルトでは無効です。ファイルはユーザーが選択したフォルダにのみ保存されます。

## プライバシー

オーディオ、文字起こし、翻訳はMac上で処理されます。OSTには、オーディオ、文字起こし、翻訳、設定、保存したセッションファイルをコンピュータの外部へアップロードまたは送信する機能はありません。

インターネット接続は、ユーザーがMLXモデルのダウンロードを選択した場合にのみ使用されます。サンドボックス化されたダウンローダーはモデルファイルを受信しますが、ユーザーのコンテンツを受け取ることはありません。

## 動作要件

- macOS 26.0以降
- Apple Silicon

## 0.2.3のインストール

[v0.2.3リリース](https://github.com/9bow/OST/releases/tag/v0.2.3)から`OST-0.2.3-macos-arm64.zip`をダウンロードして展開し、`OST.app`をアプリケーションフォルダへ移動します。

リリース環境でDeveloper ID証明書を利用できなかったため、現在のバイナリはアドホック署名されています。このリポジトリからダウンロードしたことを確認しても、macOSの隔離機能によってアプリを検証できない、または破損していると表示される場合は、隔離属性を削除してください。

```bash
xattr -dr com.apple.quarantine /Applications/OST.app
```

リリースZIPのSHA-256はリリースワークフローで公開され、次のコマンドで比較できます。

```bash
shasum -a 256 OST-0.2.3-macos-arm64.zip
```

## 文字起こしを開始する

1. OSTを起動し、macOSから求められたらシステムオーディオキャプチャを許可します。
2. メニューバーのOST字幕アイコンを選択します。
3. 入力言語と翻訳先言語を選択し、**開始**を選びます。
4. **設定 > オーバーレイ**でロックを解除し、移動、サイズ変更、確定行数の変更を行います。

## オプションのセッションファイル

**設定 > プライバシー**を開き、**セッションごとの記録をテキストファイルに保存**を有効にしてフォルダを選択します。キャプチャの開始から停止までが1つのセッションです。OSTはタイムスタンプ付きの文字起こしファイルと翻訳ファイルを別々に作成します。このオプションはデフォルトでは無効で、オーディオは保存されません。

## ビルドとテスト

このプロジェクトはSwiftPMとXcodeのアプリ/XPCプロジェクトを使用します。

```bash
swift package --disable-sandbox resolve
swift test --disable-sandbox --disable-automatic-resolution --jobs 4
script/test.sh
script/build_and_run.sh run
```

リリースチェックリストについては[docs/manual-qa.md](docs/manual-qa.md)を参照してください。
